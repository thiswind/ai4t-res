# 讲义 01 · 五件套：跟 AI 说清楚你要什么

**对应书第 1 章（1.1–1.8）｜建议用时 60 分钟｜产出：您学科的第一份五件套提示词**

## 学习目标

读完练完，您能：

1. 说出"帮我写个教案"差在哪三处（对象模糊 / 任务笼统 / 无约束）
2. 逐项写出五件套，并说明哪件最重要（学情）
3. 用书 1.5 的英语示例做底版，改出自己学科的完整提示词

## 读什么（先读书，再动笔）

| 书节 | 主题 | 读时要带走的一句话 |
|---|---|---|
| 1.1 | 差距在哪里 | 差的不是工具，是表达 |
| 1.2 | 政策地图 | 教育部文件给教师用 AI 上了"户口" |
| 1.3 | 工具选型 | 国产够用，功夫在表达——换豆包/千问/DeepSeek 不用改提示词 |
| 1.4 | 五件套 | 角色 / 学情 / 任务 / 约束 / 输出格式 |
| 1.5 | 英语示例全文 | 逐句是零件，整段是模具 |
| 1.6 | 三科对照 | 五件套是模具，学科是原料 |
| 1.7 | 两个进阶技巧 | 示例喂样例、追问给标准 |

## 跟着做

**第 1 步（10 分钟）：拆一份坏提示词。** 把"帮我写个教案"按三处毛病各写一句诊断，写在下面横线上。

- 对象模糊：＿＿＿＿＿＿
- 任务笼统：＿＿＿＿＿＿
- 无约束：＿＿＿＿＿＿

**第 2 步（15 分钟）：写学情。** 用书 1.4 的三句话标准（具体到能看见画面 / 有数字 / 有脾气），写您自己班的三行学情。写完自问：一个没见过您班的陌生人读完，能想象出这班学生吗？

**第 4 步（10 分钟）：跑一次，做两处追问。** 发给 AI，看初稿；用书 1.7 的追问技巧至少改两处（如：这里换成我学生的例子 / 这条约束没执行，重做）。

## 自检清单（全部打钩才算过关）

- [ ] 能不看书说出五件套名字
- [ ] 学情三行里有具体画面，不是"基础差、不爱学"
- [ ] 提示词五件齐全，任务里有课时数，约束里有教材版本
- [ ] 对初稿做了至少两处追问修改
- [ ] 把这份提示词存进手机备忘录（第 2 章流水线第一步要用）

## 常见卡点

| 卡点 | 解法 |
|---|---|
| 学情写不具体 | 先写一句"上节课最让我头疼的一件事"，再翻写成学情 |
| 约束不知写什么 | 抄书 1.5 约束件的四类：内容边界 / 篇幅 / 格式 / 依据 |
| AI 输出太笼统 | 检查任务件是否给了课时、环节、字数这类硬参数 |
