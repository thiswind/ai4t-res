# 讲义 04 · 自然语言造课堂小工具

**对应书第 4 章（4.1–4.8）｜建议用时 50 分钟｜产出：一个双击就能用的 HTML 小工具**

## 学习目标

1. 用"动词＋名词＋场景"公式拼出工具需求，并过"三问"安检
2. 照抄提示词造出点名器（或您的学科版）
3. 把工具存成 .html 文件并双击运行

## 读什么

| 书节 | 主题 | 带走一句话 |
|---|---|---|
| 4.1–4.2 | 为什么造工具 | 教室的痛点，小工具最划算 |
| 4.3–4.4 | 点名器实战 | 八分钟出成品的现场节奏 |

## 跟着做

**第 1 步（5 分钟）：选痛点。** 从您教室里挑一个重复劳动（点名/计时/计分/抽背）。写一句：我想造"＿＿＿"来解决"＿＿＿"。

**第 2 步（10 分钟）：拼需求+安检。** 用公式拼出需求句；过三问——单文件吗 / 断网能用吗 / 崩了怎么办（书 4.5）。三问有一问答不上，改需求再过。

**第 3 步（20 分钟）：生成工具。** 书附录 B3 点名器提示词照抄（或 B3'⑤ 默写抽背卡版），您的需求替换相应部分。AI 给出代码块后：全选复制。

**第 4 步（10 分钟）：落地运行。** 打开"文本编辑"（Mac）或"记事本"（Win）→ 粘贴 → 另存为 `点名器.html`（编码选 UTF-8）→ 双击打开。测三下：名单能粘、按钮灵、重置有效。

**第 5 步（5 分钟）：迭代一次。** 用一句增量指令改一处（"字号再大些""背景换米色"），复制新代码覆盖重存。**这就是您的第一个软件迭代经验。**

## 自检清单

- [ ] 需求句过了三问
- [ ] 工具是单个 .html 文件，双击可跑
- [ ] 测过三个功能点
- [ ] 做了一轮迭代
- [ ] 文件存在桌面"我的工具"文件夹（以后会越攒越多）

## 常见卡点

| 卡点 | 解法 |
|---|---|
| 保存后双击变成乱码 | 存储编码不是 UTF-8；用 VS Code 或换个编辑器重存 |
| 代码只显示一半 | 让 AI"完整输出，不要省略"；或说"接着上次继续" |
| 想要的功能太复杂 | 拆两步：先造能用的，再迭代加——点名器也是一轮轮加出来的 |
