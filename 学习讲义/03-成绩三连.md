# 讲义 03 · 成绩分析与学情材料（三连 + 脱敏）

**对应书第 3 章（3.1–3.11）｜建议用时 60 分钟｜产出：一份脱敏 CSV + 一份成绩分析（三连跑完）**

## 学习目标

1. 独立完成成绩单脱敏三步（平台确认→最小字段→编号替换）
2. 一个会话跑完三连（分析→分层练习→学情简报）
3. 对 AI 结果做"三笔账抽查"和一处人工删改

## 读什么

| 书节 | 主题 | 带走一句话 |
|---|---|---|
| 3.1–3.3 | 场景与红线 | 铁规矩六字：先脱敏，再上传 |
| 3.4–3.5 | CSV 与五件套 | 净表进、清楚出 |

## 跟着做

**第 1 步（10 分钟）：脱敏。** 拿一份真实成绩单（或先用书附录 C 的模拟表练手）：
①确认平台：您用的 AI 工具企业协议是否允许处理成绩——拿不准就不用真名真分（书 3.2）；
②删列：只留分析要用的列；
③替换：姓名换 01–40 号，另存 CSV。**对照表留在自己电脑，不上传。**

**第 2 步（20 分钟）：第一连。** 书 3.6 提示词全文照抄，科目名换成您的。发附件前最后看一眼：表里有姓名吗？（语文老师加练：照书 3.9 把语文拆成作文/阅读/基础分项列，跑"分项版"第一连。）

**第 3 步（10 分钟）：三笔账抽查。** 挑三处用计算器/Excel 验：全班总分对不对 / 某科平均对不对 / 最值学生对不对。发现错→"你重算第②项"。再把 AI 自定的一处口径（如优秀率定义）与学校口径对照。

**第 4 步（15 分钟）：第二、三连。** 同一会话继续（书 3.7）：分层练习→学情简报。简报回来做三处人工：换称呼、补一句人话、删一条最过度的推论。

**第 5 步（5 分钟）：登记。** 这次分析您改了几处、各是什么类型（算错/口径/语气）？记在下页——这是您的"把关账"，攒三次就有手感。

## 自检清单

- [ ] 上传前查过：表内无姓名、无学籍号
- [ ] 两句保险在提示词里（计算用代码并注口径 / 结论只依据表内数据）
- [ ] 三笔账抽查做过，至少对上一处口径
- [ ] 简报做了三处人工修改
- [ ] 知道哪类结论该删（表里没有的推断）

## 常见卡点

| 卡点 | 解法 |
|---|---|
| 不敢传成绩 | 先用模拟表练（附录 C 可自制）；真表脱敏后再用 |
| AI 算错平均分 | 正常——这就是两句保险存在的理由；让它重算并注明口径 |
| 补差点不会定 | 成绩表里看不出来；结合卷面自己定（书 3.9 语文定"默写字词"同理） |
